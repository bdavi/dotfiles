# My dotfiles and a few other things

## Note
Place this repo at `~/code/dotfiles`

## Install dotfiles
Run this to install:
`~/code/dotfiles/scripts/install_dotfiles.sh`

It symlinks everything under `config_files/` into `$HOME`, so re-run it after adding a file there - a new file is not live until you do. That includes the Claude skills under `config_files/.claude/skills/`.
